# v0.1 screens (S9 hands-on walk)

These are screenshots from the S9 hands-on walk, taken in system Chrome 155 against the real stack
(see `research/build/READER-RELEASE-RESULT.md`). They are the "before" set for the v0.2 UI revamp with
Claude Design.

- **Heads:** these are from the final release head `60ae507`:
  - `reader-390-*`, `reader-guided-*`, `reader-split-*`, `reader-contents-highlights-*`,
    `reader-unanchored-tray-*`, `reader-still-reading-*`;
  - `explain-chip-flash-*`, `explain-summary-*`;
  - `canvas-edge-note-*`, `canvas-empty-*`.

  The rest are from the earlier pre-S9 walk on release heads `7220396` and `d03f520`, so details fixed
  after those heads may differ.

- **Papers shown:** YOLO (1506.02640), DDPM (2006.11239) and ViT (2010.11929). The test account uses an
  `example.test` address.
