# ADR-004: The v0.2 UI stack (Ex Libris)

- Status: **Accepted** for v0.2 by the build session of 2026-10-16, under the owner's build prompt ("research
  first, don't reinvent the wheel, don't add a dependency you can't justify"). Open to override on #175.
- Evidence: three research notes, `research/build/v0.2-ui/RESEARCH-R1-canvas.md`, `RESEARCH-R2-ink.md` and
  `RESEARCH-R3-diagrams-motion.md`, read 2026-10-16 against shallow clones of Excalidraw (`4c37956`), tldraw
  (`1304f95`), xyflow (`654ba5a`), BlockSuite (`5cb5cb6`), perfect-freehand, rough.js, Drawably, elkjs,
  dagre, d3-hierarchy, mermaid-to-excalidraw, Motion and TanStack Virtual. Bundle sizes are min+gz measured
  with esbuild or `npm pack` + `gzip -9` in a scratch folder, not in a Next build, so they are upper-bound
  estimates. Each note marks what it could not verify **NOT CONFIRMED**.
- The design is `PaperTree-design/v0.2/from-claude-design/F-final/live/project/DESIGN.md` (the owner's
  final, Theme A "Ex Libris").

## 1. Decisions in ten lines

1. **No new canvas engine.** The board stays on `@xyflow/react` 12 (MIT, already shipped); the notebook is our
   own React-DOM page with an SVG ink layer. Two surfaces, as DESIGN.md §7 says.
2. **Ink = `perfect-freehand` 1.2.3** (MIT, 2 KB gz) plus our own pointer recorder, stroke store, eraser and
   lasso. The only new runtime dependency of the whole revamp besides fonts.
3. **tldraw is not adopted** (its licence forbids production use without a key and enforces a watermark):
   **owner's call**. Excalidraw (MIT, ≈1 MB gz, canvas text) is not adopted; it stays the documented fallback
   for ink only.
4. **Board extras are ours:** typed port pins, the "Link as" picker (keys 1–7), frames, deep undo, keyboard
   linking. React Flow Pro's undo example is under a paid licence and must not be copied.
5. **Diagrams:** the model streams an NDJSON spec (parts with a verbatim quote each, or null for "inferred");
   the server resolves quotes to `Anchor`s; the web lays parts out on our own slot grid and draws an SVG plate
   with SVG-pattern hatching. **elkjs is not adopted** (EPL-2.0 OR GPL-3.0, 440 KB gz): **owner's call**.
   rough.js and dagre are not needed.
6. **Motion = CSS transitions + the Web Animations API**, no Motion library (it would add 33–47 KB gz). Every
   moment has a reduced-motion path from the tokens.
7. **No virtualisation** for the 400-spine shelf or the 400-row Table: they measure at 7–15 ms to build; we use
   `content-visibility: auto` per row and count search matches from data. TanStack Virtual (MIT, 10 KB gz) is
   the named fallback.
8. **Tokens:** the Ex Libris values from `tokens.css` replace the `--pt-*` values under the same names (aliased
   where a name changes), both schemes, with a `data-theme` switch over `prefers-color-scheme`.
9. **Fonts via `next/font/local` from `@fontsource/*` packages** (Libre Caslon Display and Text, Alegreya Sans and
   Sans SC, Courier Prime; SIL OFL 1.1): self-hosted, offline-safe, pinned by the lockfile.
10. **Drawably is not adopted** (a random sketch per mount and a 1.2 s "boil" fight "calm, exact" and stable
    screenshots); the hand-drawn look is our own ink and SVG.

## 2. Surface by surface

### 2.1 Tokens and theming

- **Chose:** keep the `--pt-*` names in `packages/ui/src/styles.css` and give them the Ex Libris values from
  `tokens.css` for daylight and the lamp-lit study. New roles (AI slip, call slip, linen, reader desk, pen,
  margin tab, ribbon, sticky, the six cloths, gilt, brass, walnut, the seven thread colours, elevations e1–e3)
  are new `--pt-*` tokens. A name that no longer fits gets an alias to its new token, never a deletion, so no
  surface silently loses its colour. Scheme: `:root[data-theme="dark"]` plus
  `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }`; the switch lives in the
  reading-settings menu (Aa) and is stored per browser.
- **Rejected:** a Tailwind theme rewrite (Tailwind stays for layout utilities only; colour comes from tokens, so
  both schemes are one CSS file); CSS-in-JS (runtime cost, SSR flash).
- **Bundle cost:** CSS only.
- **Risks:** v0.1 class families (`pt-cv`, `pt-s3`, `pt-explain`, …) carry hard-coded spacing that drifts from the
  new scale until each surface is rebuilt; S1 aliases first, the slices replace.

### 2.2 Fonts

- **Chose:** `next/font/local` over the woff2 files in `@fontsource/libre-caslon-display`, `…-text`,
  `@fontsource/alegreya-sans`, `…-sans-sc` and `@fontsource/courier-prime` (5.3.0, OFL-1.1), latin subset, the
  weights DESIGN.md uses. `next/font` gives preloading, `size-adjust` fallbacks and no layout shift.
- **Rejected:** `next/font/google` (fetches at build time, so an offline or firewalled build fails, and this app
  is local-first); committing font binaries (the packages already pin them).
- **Licence:** OFL 1.1 is a font licence that allows bundling and embedding in software; it is not a code
  licence. The design names these faces, so the owner's choice of design is the choice of fonts.
- **Bundle cost:** about 8 woff2 files, 15–40 KB each, loaded per page as used (NOT CONFIRMED until S1 measures).

### 2.3 Library and shelf

- **Chose:** DOM + CSS for spines, plank, label holders and the face-out covers (01c); the shelf layout
  (rows per topic, spine width from page count capped at 48 px, "+n more" bookends) is a pure function in
  `features/library/model/`. Search filters in place by dimming (`data-match`), never by reordering. Table:
  a real `<table>` with sortable headers. Map: an SVG plan with topic islands, and only real links (shared
  references matched by arXiv id or title, each labelled with how it matched). Topics: cards whose banner is
  the paper's Figure 1 crop, a cloth pattern, or an ornament.
- **Rejected:** canvas or WebGL shelves (accessibility, text quality); virtualisation (measured unnecessary at
  400, R3 §5); a force layout for the Map (would invent "similarity" closeness).
- **Bundle cost:** 0 KB of dependencies.
- **Risks:** React re-render cost of 400 spines on each search keystroke (not measured in React): memoise spines
  and drive the dim with one attribute on the shelf.

### 2.4 Pull out and the opened book

- **Chose:** CSS 3D (`perspective` on a stage, `preserve-3d`, cover hinge `transform-origin: left`,
  `rotateY(-160deg)`, endpaper on the back face) driven by WAAPI with the DESIGN.md §6 timings; reduced motion is
  one 120 ms cross-fade. Both pages are real DOM, so the text stays selectable and reachable.
- **Rejected:** Motion `layoutId` morphs (scale-distorts text, needs `domMax`, +47 KB).
- **Risks:** Safari `backface-visibility` quirks (NOT CONFIRMED; test on Safari).

### 2.5 Reader

- **Chose:** keep pdf.js 5 and the v0.1 reader core (Source, Guided, Split, highlights from stored quads); restyle
  with tokens and the Ex Libris chrome (reader desk, margin page tabs, the selection toolbar in the margin or
  docked at the top of the column, never over the lines being read).
- **Rejected:** a second PDF renderer.
- **Risks:** #176's selection leftovers live here; the revamp must not regress the v0.1 e2e suite.

### 2.6 Explain and trace (ask → answer → trace)

- **Chose:** one `Exchange` layout component composed of `CallSlip` (the ask), `AiSlip` (the answer with numbered
  markers and margin tabs) and `TraceList` (numbered passages with "Show in paper") under a `CoverageReadout`.
  **Markers are numbered by passage:** a pure function maps the answer's citations (anchors) to passage numbers
  in order of first use, so the same passage keeps the same number in the answer, the trace and every later
  surface. The layout is one component behind a small interface, so frame 13's sidenote or claim → evidence
  variants could replace it later (owner may change, decision 1). Exchanges are named by their asks.
- **Rejected:** per-claim chips ("p. 3 p. 3 p. 3", the v0.1 defect).
- **Bundle cost:** 0 KB.
- **Risks:** the grounding check is lexical (#179); the trace makes a misattribution visible but cannot catch it.

### 2.7 Dive-in notebook

- **Chose:** a page model of positioned items in **fixed page units** (a logical page width; the page scales as a
  whole, so ink never drifts against typed blocks): an exchange block (call slip, AI slip, trace as quote cards),
  typed text, stickies, quote cards and shapes as DOM/SVG; an SVG ink layer on top. Pen, highlighter, stroke
  eraser and polygon lasso; strokes are `perfect-freehand` outlines of stored raw points. Lasso selection,
  eraser hit-testing and stroke encoding are pure, unit-tested functions. Templates (blank, dot grid, lined,
  Cornell, derivation grid) are CSS/SVG backgrounds. Storage: SQLite rows per item and per stroke; quote cards
  and AI citations keep **`Anchor`s, never bare block ids** (AGENTS.md §4). Phone shows the same page as a stack
  with view-only ink; the pen is opt-in.
- **Rejected:** Excalidraw (canvas text cannot carry the three voices or clickable markers accessibly; ≈1 MB gz);
  tldraw (licence); BlockSuite (Lit, MPL, stale since 2025-07); a rich-text framework such as TipTap (typed
  blocks here are short plain paragraphs; revisit if formatting is asked for).
- **Bundle cost:** +2 KB gz (`perfect-freehand`).
- **Risks:** ink feel on a real iPad (latency, pressure, palm rejection) is unproven in a DOM/SVG layer; plan a
  device pass, with lazy-loaded Excalidraw ink as the fallback. `getCoalescedEvents` needs HTTPS or localhost
  on iOS 18.2+.

### 2.8 Board

- **Chose:** `@xyflow/react` 12 with paper-styled custom nodes (index cards: passage, note, question, notebook
  page, diagram; AI-slip cards: explanation), typed handles as brass port pins (evidence in, question in, claim
  out, answer out) checked by `isValidConnection`, custom edges for the seven relation kinds (colour **and** a
  stitch or glyph, plus a paper tag), the "Link as" picker opened from `onConnectEnd` at the midpoint (4 + 3
  grid, keys 1–7, Esc = plain link), frames as parent nodes with dashed outlines and paper tags, `MiniMap`
  restyled, our own command-stack undo/redo, and a keyboard way to start and finish a link (xyflow has none).
  At 500 nodes: memoised nodes, `onlyRenderVisibleElements`, and a simplified card render at low zoom.
- **Rejected:** tldraw (licence); copying React Flow Pro's undo example (paid licence); a custom node editor.
- **Bundle cost:** 0 KB new (xyflow ≈60 KB gz already ships).
- **Risks:** 500 rich cards (R1: xyflow's stress example is 625 plain nodes); keyboard linking is ours to build.

### 2.9 AI diagrams

- **Chose:** a new run kind `diagram`. The agent prompt (in `services/agent/src/prompts.ts`, beside the other
  prompts; `packages/prompts` is the Python datamark and sanitising helpers only, corrected by the gap audit) asks for NDJSON lines (`plate`,
  `part`, `link`, `end`); a part's `after` may name only earlier letters (acyclic by construction); `cite` is a
  required, nullable verbatim quote. The agent validates each line with the zod already in the workspace
  (server side only); the API resolves quotes to `Anchor`s with the existing lexical checker; an unresolved
  quote is "not verified", a null one is dashed "inferred, no passage". The web places each part on a slot
  grid the moment it arrives (slots never move; the plate grows downward; Stop freezes it) and draws the plate
  in SVG with `<pattern>` hatching. Usage line and daily cap as for every run.
- **Rejected:** elkjs (licence EPL-2.0 OR GPL-3.0-or-later and 440 KB gz; its layered layout also moves the main
  column) — **owner's call**; dagre (moves columns on re-run); rough.js (non-deterministic by default, stale);
  Mermaid (fragile model syntax, DOM scraping); generated images (there is no image model).
- **Bundle cost:** 0 KB.
- **Risks:** whether M3.1 Flash emits strict NDJSON with quotes that resolve is unmeasured until S7's live smoke.

### 2.10 Motion

- **Chose:** CSS transitions for state changes (marker ↔ trace light, search dimming) and the Web Animations API
  for choreography (pull out as one 400 ms animation with offsets, the 1,680 ms citation flash, FLIP for Dive
  in), a small rAF tween for the 240 ms scroll. Durations and easings come from tokens; `prefers-reduced-motion`
  collapses each to the DESIGN.md §6 reduced row.
- **Rejected:** Motion / framer-motion (+33 KB gz with `LazyMotion`, +47 KB with layout); `motion/mini` (3.4 KB)
  stays the fallback if FLIP moves multiply. View Transitions (same-document support NOT CONFIRMED in all
  target browsers).
- **Risks:** hand-written FLIP is fiddly; keep it in one helper with tests for the reduced path.

## 5. Consequences

- The revamp adds ~2 KB gz of runtime dependencies plus fonts; everything else is our code, in feature folders
  with pure, tested models (`features/*/model/`).
- v0.1's principle "no fabricated diagrams" (`packages/ui/src/provenance.tsx`, `FigureView`) is narrowed, not
  dropped: the paper's own figure is still the only figure shown as the paper's; an AI diagram is drawn on the
  AI slip, under the AI tab, with every part cited or marked "inferred, no passage".
- Two things need a real device: ink on an iPad with a Pencil, and the 3D book in Safari.
